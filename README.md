# 555 Timer LED Blinker PCB

This project is a simple LED blinker circuit using the NE555 timer IC designed in KiCad.

## Features
- Astable multivibrator circuit
- LED blinking output
- PCB designed in KiCad

## Components
- NE555 Timer IC
- Resistors
- Capacitor
- LED
- Battery

## Software Used
- KiCad

## Output
LED blinks continuously using hardware timing.
